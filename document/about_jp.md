# QuickAppsTest — バージョン情報

## バージョン

v1.0.0（skeleton）

## コンセプト

Quick シリーズのデスクトップアプリを検査する再利用 Python ライブラリです。出荷する Windows GUI ではありません。

## 開発環境

- Python 3.11+
- Playwright（WebView2 は `connect_over_cdp`。後続 PR）
- pywinauto（ネイティブ Win32。後続 PR）
- Appium 2 Windows driver（任意のアクセシビリティ。後続 PR）

このリポジトリに MinGW、WebView2 SDK、`bundle_html.py` は置きません。
